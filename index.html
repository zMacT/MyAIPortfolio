Featured Projects

Check I/O Scanner Application

Honors Thesis Project | 2024

A lightweight Java-based check-in/out system using the javax.swing.* package for graphics. Check-in/out is done using a Symbol LS2208 Barcode Scanner and the Zebra Scanner SDK w/ JPOS. Logs are automatically saved when the window is closed. Ideal for organizations seeking to localize check-in/out solutions.

Java Swing Barcode Scanner SDK JPOS

NIH Project Funding Analysis

Research Project | Summer 2023

A research project with the goal of discovering patterns between research abstracts and request for applications (RFAs). A Python library (gensim) is used to calculate the cosine similarity between these two documents. A line of best fit is plotted to represent the relationship between wording similarity and total funding awarded to the researchers. These trends may help prospective researchers find improved ways to write their project abstracts to receive the funds that they need.

Python Gensim Data Analysis NLP
